카카오톡 대화 요약 & 타임라인 기록 시스템이 프로젝트는 카카오톡 특정 대화방의 내용을 백업 및 요약하고, 타임라인과 검색 기능을 제공하는 반응형 웹 대시보드와 데이터 수집용 파이썬 스크립트로 구성되어 있습니다.1. 전체 아키텍처 구성[카카오톡 대화 내보내기 (.txt)]
       │
       ▼ (수동 업로드 또는 Google Drive 연동)
[파이썬 파서 & 분석 스크립트 (kakaotalk_parser.py)]
       │
       ├─► [구글 스프레드시트 / Local JSON] (데이터 저장)
       └─► [Gemini 2.5 Flash API] (주간/일간 대화 요약 자동 생성)
               │
               ▼ (데이터 동기화 및 깃허브 배포)
[인터랙티브 웹 대시보드 (index.html)]
  - 대화 요약 카드 리스트 (클릭 시 해당 대화로 이동)
  - 주차별 / 날짜별 캘린더 & 메신저형 타임라인 뷰
  - 참여자별 통계 및 대화 검색창
2. 자동 기록 구현 방법 가이드방법 A: 구글 스프레드시트 자동 동기화 (추천)구글 클라우드 콘솔에서 서비스 계정을 생성하고 Google Sheets API를 활성화합니다.다운로드받은 서비스 계정 자격 증명 JSON 파일을 파이썬 스크립트와 동일한 폴더에 둡니다.구글 스프레드시트를 생성하고, 공유 기능으로 서비스 계정 이메일을 편집자로 추가합니다.kakaotalk_parser.py를 실행하여 텍스트 파일을 분석하고 시트에 데이터를 밀어넣습니다.방법 B: 안드로이드 Tasker/Macrodroid를 통한 실시간 수집안드로이드 기기에 Macrodroid 앱을 설치합니다.매크로 트리거: 알림 수신(Notification Received) -> 대상 앱: 카카오톡매크로 동작: HTTP POST 전송 -> 목적지: Google Apps Script Webhook 주소전송할 쿼리 파라미터:sender: {not_title} (보낸 사람)message: {not_sub_text} (메시지 내용)time: {system_time} (현재 시각)room: {notification_context} (대화방 이름)3. 웹 대시보드 (index.html) 배포 방법 (GitHub Pages)본 레포지토리의 index.html은 단일 파일로 구성된 초호화 대시보드입니다. 모바일과 데스크톱 화면에 맞춰 유연하게 레이아웃이 변하며, Tailwind CSS 및 Lucide 아이콘이 포함되어 있습니다.GitHub 저장소 생성: 새로운 Public/Private Repository를 만듭니다.파일 업로드: index.html 파일을 루트(root) 폴더에 업로드합니다.GitHub Pages 활성화:Repository 설정(Settings) -> Pages 메뉴로 이동합니다.Build and deployment 소스를 Deploy from a branch로 설정하고, main 브랜치의 / (root)를 선택 후 Save를 클릭합니다.접속: 약 1~2분 후 생성되는 https://[사용자ID].github.io/[저장소이름]/ 주소로 접속하면 전 세계 어디서든 대화 요약 대시보드를 사용할 수 있습니다.4. 웹 대시보드 핵심 기능 개요메인 요약 대시보드: 주차별/일자별로 자동 그룹화된 대화 요약 리스트를 제공합니다. 요약 카드를 클릭하면 즉시 해당 날짜의 대화 타임라인으로 스크롤 및 포커스가 이동합니다.캘린더/일자별 타임라인: 마치 카카오톡을 직접 보는 듯한 깔끔한 말풍선 타임라인을 주차별/날짜별로 조회할 수 있습니다.AI 실시간 요약 엔진: 대시보드 내 "새 대화 업로드" 탭에서 카카오톡 텍스트 파일을 업로드하거나 붙여넣고 본인의 Gemini API Key를 입력하면, 브라우저가 직접 Gemini 2.5 Flash를 통해 전체 대화를 정밀 분석, 주제 분류, 요약본 생성을 자동으로 수행하여 대시보드에 추가합니다.검색 & 통계: 대화 내용 검색 기능 및 참여도 통계 분석 차트가 탑재되어 있습니다.
